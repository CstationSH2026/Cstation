# 西岸读书会网页更新说明

## 第一次切换
把本包中的 index.html 和整个 posters 文件夹放在网站同一目录。首次需要上传完整包，因为旧海报已统一改名。

## 今后每次更新
1. 把新一期内容、日期和海报发给我，我返回更新后的 index.html，并告知海报名称。
2. 将新增海报上传到 posters 文件夹，覆盖网站原来的 index.html，刷新网页。
3. 旧海报不用重新上传，也不要删除 posters 文件夹。

## 固定命名规则
- 网页入口始终为 index.html，不添加日期或版本号。
- 海报统一为 posters/issue-期号-v版本.jpg，例如 issue-22-v1.jpg、issue-22-v2.jpg。
- 期号至少两位；版本号保留原始版本，如第12期的 v3 仍为 issue-12-v3.jpg。
- 全部路径采用英文小写、数字和连字符，不含中文或空格。
- 图片须为实际 JPG 格式；不能仅把 PNG 后缀改成 .jpg。
- 原文件名和新路径对应关系见 filename-map.csv，仅供核对，不影响网页运行。

## 网页资料
所有活动资料均在 index.html 的 DATA 数组内；新增一期时更新此文件即可，无需额外 JSON 文件。
imgs 为海报相对路径，sizes 为各海报实际 [宽度, 高度]，顺序一一对应。切换海报会按相应尺寸完整显示。
期数、展示月份、首页统计和结尾期数根据活动资料自动更新。ARCHIVE_YEAR 为归档年份。
上传海报不会自动新增活动文字，仍需同步更新 index.html。

## 替换海报
如果只更新已有海报且像素尺寸不变，可以覆盖相同路径。若浏览器缓存旧图，请强制刷新。
如果像素尺寸改变，请同步更新 index.html 中对应 sizes。也可增加 v3 等新版本并更新 imgs 和 sizes。

## 保留内容
21期、40张海报；原图比例；统一档案格式；已确认的结尾全文和“西岸读书会藏书”。
