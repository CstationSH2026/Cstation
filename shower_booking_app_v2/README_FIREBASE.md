# 云数据库部署指南

本版本的洗浴预约应用使用云数据库作为后端存储，解决了多用户数据同步的问题。以下是完整的部署步骤：

## 1. 创建云数据库项目

1. 访问云服务提供商的控制台
2. 创建一个新的项目
3. 启用实时数据库服务

## 2. 设置数据库

1. 在控制台中，创建一个新的数据库实例
2. 选择合适的区域（建议选择离用户较近的区域）
3. 设置适当的安全规则，允许读写操作

## 3. 获取数据库配置

1. 在项目设置中找到Web应用配置信息
2. 复制生成的配置代码，包含apiKey、authDomain、databaseURL等信息

## 4. 更新应用代码

1. 打开`index.html`文件
2. 找到数据库配置部分，用您获取的配置替换示例配置
3. 保存文件

## 5. 部署应用

您可以使用之前提供的任何部署方法（GitHub Pages、Netlify、Vercel等）来部署更新后的应用。

## 6. 测试应用

1. 打开部署后的应用
2. 提交一个预约
3. 在另一台设备或浏览器中打开相同的应用
4. 验证预约数据是否同步显示
5. 测试导出功能，确认可以导出所有用户提交的预约数据

## 7. 生产环境安全建议

当您准备将应用部署到生产环境时，建议：

1. 更新安全规则，限制只有授权用户才能写入数据
2. 添加用户认证机制，保护管理功能
3. 设置数据过期策略，定期清理旧的预约数据
4. 监控应用使用情况，及时发现并解决问题

## 故障排除

1. **数据不同步**：
   - 检查数据库配置是否正确
   - 确认网络连接正常
   - 查看浏览器控制台是否有错误信息

2. **无法提交预约**：
   - 检查数据库规则是否允许写入
   - 确认数据库服务是否已启用

3. **导出功能失败**：
   - 检查是否有足够的预约数据
   - 确认浏览器是否允许下载文件

如有其他问题，请参考相关云服务提供商的文档或联系技术支持。
